# Complex stack composition (Rules 5–7)

Jesse's rules (`~/Documents/first priniples/05_Cognitive_and_Quantum_Roots/Atom_Architecture_Rules/`):
- **Rule 5:** ≥2 chaos-derived mechanisms of *different dynamics* (e.g. logistic map and Hénon
  map), at different positions; run no-chaos, each single, and multi-chaos controls; promote only on
  strict improvement.
- **Rule 6:** the principal candidate uses genuine mechanisms from quantum, mechanics & theory,
  physics, information theory, chemistry, cognition. Document each: state, invariant, interaction
  point, falsifier, why chosen. Ablate each domain.
- **Rule 7:** compositional complexity; simple stacks are controls/diagnostics only; precommit 1–3
  orders; run every declared arm; keep failures.
- **Jesse 2026-10-24:** add neuroscience and biology too; "there is no limit to complexity — the more
  complexity can often lead to better outcomes" (treat as a theory to test: larger vs smaller
  composition).

## Mistakes already made (don't repeat)
- Writing "chaos: none" or "amplification: a lighter load" — both are missing arms.
- Shipping single-law POCs as if they were the build.
- Composing only physics + one other domain.

## Precommit template (every experiment)
1. The task, the frozen metric, hard invariants, seeds (dev chooses every threshold, test reports).
2. A table: domain · mechanism · state · invariant · interacts with · falsifier (ablation) · why.
   Cover quantum, mechanics/thermo, physics, information theory, chemistry, cognition,
   neuroscience, biology.
3. 1–3 declared orders, each with its reason.
4. Chaos: two maps (different dynamics) at two positions, each with the stack's own selector; plain
   wins ties; controls none/single/both.
5. Amplification that is truly "more of what exists" (more rounds, more modules, more gain).
6. Arms list with bounded count; predictions with numbers; what each failure would mean.
7. Status-quo bars; existing stacks are bars only, never the basis ("we are looking for better").

- Physics + **cognitive PERCEPTION gate** → recall that runs its loop only when the store is

- **Repair/healing laws by domain** (HOLO-R): neuroscience replay; chemistry autocatalysis (repair in

- **Biology candidates:** kinetic proofreading, immune self/non-self, apoptosis, regeneration,

## Order can matter more than any domain (HOLO-R, 2026-10-24)
The same eight-domain mechanisms in two declared orders: decode-first healed a holographic store
through lifelong damage (0.939 after losing 6 of 8 regions; plain 0.077); perceive-first failed
(0.107), because its perception (each part probed alone) was blind. Always declare ≥2 orders, and
run ablations on the order that works. Ablations measured on a broken principal are inconclusive,
not negative.
